Bhawana - Portfolio
===================
Open index.html in any browser to view the site.

Folder structure
  index.html        page content
  css/style.css     all styling
  js/script.js      3D mouse movement + scroll effect for the photo
  images/bhawana.jpg  your photo (replace with a new one, keep the same name)

To edit: change text in index.html. Replace the '#' links (GitHub, LinkedIn,
LeetCode, Live demo) with your real URLs.
To host free: upload this folder to Netlify, Vercel or GitHub Pages.
